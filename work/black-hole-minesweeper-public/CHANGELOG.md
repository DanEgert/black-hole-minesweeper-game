# Changelog

## 1.0.0 — 2026 public edition

- Packaged the pandemic-era MATLAB game as a stable `BlackHoleMinesweeper` entry point.
- Added six cohesive images created specifically for the public edition.
- Replaced the synthetic mission narration with an on-screen briefing.
- Removed all third-party and uncertain-provenance media.
- Resolved assets relative to the project folder.
- Removed reliance on undocumented MATLAB interfaces and unnecessary toolbox functions.
- Added a MATLAB Compiler helper for a standalone Windows installer.
- Added MIT licensing, artwork provenance, and public release documentation.
